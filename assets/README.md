# Profile Icons

These icons identify the destinations of profile links and are bundled locally so the pages do not request remote images.
The PNG files were downloaded unmodified on September 18, 2026.

- `acm-icon.svg`: the visualization's existing blue diamond and white ACM lettering, extracted unchanged from its inline SVG.
- `google-g.png`: [Google's multicolor G](https://www.gstatic.com/images/branding/googleg/1x/googleg_standard_color_128dp.png), used for Google Scholar links at the user's request.
- `dblp-icon.png`: [DBLP's site icon](https://dblp.org/img/dblp.icon.192x192.png), referenced by DBLP's own page icon metadata.

Keep this directory alongside the visualization HTML, JavaScript and CSS when copying or publishing the site.
